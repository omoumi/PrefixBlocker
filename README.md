# Prefix Blocker

A simple Android app that blocks incoming calls from numbers starting with prefixes you choose.

## Features
- Block calls by prefix (for example `0912` or `+1800`)
- On/off switch to pause blocking anytime
- History of blocked calls
- Light and dark mode

## How to use
1. Download the latest APK from [Releases](../../releases) and install it.
2. Open the app and tap **Enable call blocking**.
3. Add your prefixes (one per line) and tap **Save**.

## Notes
- Requires Android 10 or newer.
- Numbers saved in your contacts may not be blocked.
- Only calls are blocked, not SMS.
